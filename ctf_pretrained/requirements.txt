#
#   pip install -r requirements.txt
#   pip install --no-deps facenet-pytorch==2.6.0
#
# Two rules:
#
# 1. Do NOT reinstall torch/torchvision on Colab. They are preinstalled and
#    matched to the driver. The floors below are for local installs only; pip
#    will leave Colab's versions alone because they already satisfy them.
#
# 2. facenet-pytorch MUST be installed with --no-deps. Its dependency block
#    pins an older torch, and without --no-deps pip will silently downgrade
#    Colab's torch, which breaks CUDA. That is why it is not listed here.
# ---------------------------------------------------------------------------
